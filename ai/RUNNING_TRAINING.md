# ผลการฝึกที่เสร็จแล้ว

## รอบปรับปรุง public-v3 — จบแล้วและคงรุ่นเดิม

ชุดข้อมูลใหม่มี 1,715 ภาพ (train 1,426 / validation 147 / test 142) เพิ่มภาพขวดที่ตรวจป้ายกำกับแล้ว 390 ภาพเฉพาะ train ฝึกจริง 25 จากสูงสุด 35 รอบ และหยุดเมื่อ validation ไม่ดีขึ้นต่อเนื่อง 12 รอบ ประวัติ CSV และ log ยืนยันจำนวนรอบจริง

ผลเทียบ validation ภาพ 800 พิกเซล: รุ่นเดิม mAP50–95 38.32% รุ่นทดลอง 37.23% ผลขวดเพิ่มจาก 37.16% เป็น 39.09% แต่ฝาขวดลดจาก 39.48% เป็น 35.37% ไม่ผ่านเกณฑ์เพิ่มค่าเฉลี่ยและรักษาผลรายคลาส จึงคง public-v2 ที่เผยแพร่ไว้ ไม่มีงาน GPU ที่ต้องฝึกต่ออัตโนมัติ

อ่านรายงานที่ `../frontend/assets/models/TRAINING_V3_REPORT_TH.md` ชุด test เดิมเคยเปิดผลแล้ว รอบนี้ไม่ได้ใช้เลือกโมเดลและไม่ได้ประเมินซ้ำ ยังไม่มีข้อมูลจากกล้องบนเรือจริง รอบถัดไปควรประเมินความต้องการข้อมูลก่อนเริ่มงานฝึกใหม่

## รุ่นที่เผยแพร่ public-v2

เริ่มฝึกวันที่ 27 ตุลาคม 2569 บน NVIDIA GeForce RTX 2050 ของเครื่องนี้

- ชุดอุ่นเครื่อง TACO และ SC-FloatWaste รวม 910 ภาพ: train 621 / validation 147 / test 142
- ชุดปรับละเอียดเพิ่ม Reviewed ExtendedTACO เฉพาะ train เป็น 1,325 ภาพ: train 1,036 / validation 147 / test 142; ฝาขวดใน train 746 ชิ้น
- ป้ายกำกับสองคลาส: plastic_bottle และ bottle_cap; แยกกลุ่มและตรวจภาพซ้ำก่อนแบ่งข้อมูล
- อุ่นเครื่องเสร็จ 40 epochs เก็บ checkpoint ที่ดีที่สุดไว้ก่อนเริ่มรอบปรับละเอียด
- งานปรับละเอียด YOLO26n เสร็จ 60 epochs: early stopping 20, ภาพฝึก 960, batch 8, CUDA
- ตรวจความคืบหน้าที่ `runs/public-yolo26n-v2/status.json`
- บันทึก console ที่ `../../work/warirak_yolo_refinement.log`
- Python ที่ใช้ฝึก: `../../work/warirak_training_runtime/Scripts/python.exe`
- น้ำหนักและผลทดสอบสุดท้ายอยู่ที่ `runs/public-yolo26n-v2/evaluation.json` ผลใน `status.json` เป็น diagnostic 960 ระหว่างกระบวนการ ไม่ใช่ผลเผยแพร่สุดท้าย

เลือก checkpoint และขนาดภาพจาก validation ตาม protocol ที่กำหนดก่อนประเมิน test แล้ว ได้โมเดลปรับละเอียดที่ขนาด 800 × 800 พิกเซล: validation mAP50–95 38.35% ส่วน test 142 ภาพได้ mAP50 42.23% และ mAP50–95 29.44% ไม่ใช้คะแนน test เลือกโมเดลหรือขนาดภาพ

ส่งออก NCNN ที่ขนาด 800 พิกเซลและประเมินบน CPU ของคอมพิวเตอร์แล้ว ได้ test mAP50–95 29.41% ต่างจาก PyTorch ประมาณ 0.024 จุดเปอร์เซ็นต์ ยังไม่มีผล FPS ที่วัดบน Pi 4 และยังไม่ทดสอบกล้องเรือจริง ข้อมูล แหล่งที่มา เกณฑ์ความเชื่อมั่น และประวัติฝึกอยู่ในชุดส่งมอบ

ส่วนการขับในตัวจำลองฝึกเสร็จแล้ว เลือกนโยบาย 20,000 รอบจาก validation และทดสอบสนามใหม่ 1,000 สนาม: เก็บสำเร็จ 981, ชน 14, หมดเวลา 5 ผลนี้เป็นของตัวจำลอง ไม่มีคำสั่งส่งไปมอเตอร์จริง
