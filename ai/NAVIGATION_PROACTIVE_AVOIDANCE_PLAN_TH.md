# แผนศึกษาการหลบสิ่งกีดขวางล่วงหน้าหลัง R3

เอกสารนี้เป็นคิวงานออกแบบ ไม่ใช่ protocol สำหรับเริ่มฝึก และยังไม่มีนโยบายใหม่ที่พร้อมใช้งาน

## หลักฐานและสมมติฐาน

R3 ไม่ผ่าน validation ในการวิเคราะห์แบบจำกัดจากฉากฝึกเดิม 24 ฉาก พบ 11 ฉากที่นโยบายสุดท้ายถูกจำกัดให้สั่ง STOP เพราะระยะปลอดภัยต่ำกว่า 0.35 เมตร จากนั้นแรงขับดิจิทัลเป็นศูนย์จนชน ตัวจำลองยังมีความเฉื่อยและกระแสน้ำ อีก 9 ฉากชนหลังขอความช่วยเหลือ เหตุการณ์เหล่านี้แยกจากกันตามเวลา ไม่ใช่การพิสูจน์สาเหตุของทุกกรณี

สมมติฐานที่จะตรวจคือ การแทนสถานะปัจจุบันและการตัดสินใจก่อนถึงเขตหยุดอาจให้ข้อมูลไม่พอสำหรับการหลบล่วงหน้า โดยเฉพาะด้านข้าง/ด้านหลังและการเคลื่อนที่ตามขวาง การเพิ่มรอบฝึกเดิมไม่แก้ข้อจำกัดของข้อมูลที่ไม่อยู่ในสถานะโดยตรง สมมติฐานนี้ยังไม่ผ่านการทดลองเปรียบเทียบ

## งานถัดไปที่ทำได้ก่อนฝึก

1. ใช้หน้าต่างเหตุการณ์ที่บันทึกแล้วใน `work/navigation-r3-postmortem/diagnostic.json` ตรวจการแทนสถานะและช่วงเปลี่ยนผ่านก่อน STOP โดยไม่เล่นฉากหรืออัปเดต Q-table ซ้ำ แยกเหตุที่ข้อมูลสูญหาย เหตุที่ถูกตัวกำกับจำกัด และเหตุที่นโยบายเลือกเอง เก็บเลข seed เวลาเดิม และข้อจำกัดของหน้าต่างสั้นไว้ครบ
2. ออกแบบ schema ของข้อมูลสังเกตใหม่แยกจาก R2/R3 พิจารณาระยะทั้งแปดทิศที่สด การเคลื่อนที่ตามยาว/ตามขวางที่วัดอย่างอิสระ ความไม่แน่นอน อัตราหมุน และประวัติคำขอกับรายงานคำสั่งที่ใช้จริง ข้อมูลที่ไม่พร้อมต้องเป็น unknown ห้ามสร้างความเร็วจากแรงขับที่สั่ง
3. ทดสอบการรักษาความหมายของเวลาและกรอบพิกัด การเปรียบเทียบ ray เดิมหลังเรือหมุนอาจเป็นคนละทิศ จึงห้ามแปลงเป็นความเร็วเข้าใกล้อัตโนมัติ ต้องมีหลักฐานการจัดแนวพร้อมขอบเขตความไม่แน่นอน หรือระบุว่าคำนวณไม่ได้ ระยะแปดทิศไม่รับรองพื้นที่ว่างระหว่างแนวตรวจทั้งหมด
4. สร้างกรณีทดสอบกำหนดผลล่วงหน้าสำหรับการหลบก่อนถึงเขตหยุด ความเฉื่อย กระแสน้ำตามขวาง ภาพ/ระยะขาดหาย ACK ไม่ตรง คำสั่งหมดอายุ การควบคุมเอง และการปลดการทำงาน อาจเพิ่มตัวเสนอการหลบล่วงหน้าบนข้อมูลสังเกต แต่ต้องผ่านตัวกำกับอิสระเดิมทุกครั้ง ไม่คืนคำสั่งที่ถูกยกเลิกและไม่สร้างการแก้ติดค้างอัตโนมัติ
5. เมื่อมีหลักฐานจากกรณีทดสอบ จึงเลือกวิธีเรียนรู้ที่เหมาะสมและกำหนด protocol ใหม่พร้อม hash งบฝึก เกณฑ์ และ seed ก่อนเริ่ม ไม่เพิ่มมิติ Q-table อย่างไม่มีขอบเขตหรือเริ่มฝึกเพียงเพราะงานเดิมจบ

## เงื่อนไขที่คงไว้

เก็บซอร์ส ฟิสิกส์ กระแสน้ำ ตัวกำกับระยะปลอดภัย และหลักฐานของรอบ R2/R3 ไว้ตาม hash ห้ามแก้ย้อนหลัง นโยบาย/schema ใหม่ต้องมีชื่อรุ่นใหม่ การเก็บข้อมูลจำลองใช้พิกัดจริงได้เฉพาะสำหรับรางวัล การวัดผล หรือการวิเคราะห์ ห้ามส่งข้อมูลโลกที่นโยบายไม่ควรเห็นเข้าเป็นคุณลักษณะ

สถานการณ์ความหน่วง 600 มิลลิวินาทีไม่สามารถรับประกันการใช้คำสั่งที่มีอายุ 400 มิลลิวินาทีได้ภายใต้ข้อกำหนดปัจจุบัน ต้องรายงานว่าไม่พร้อมและนับผลการลอย/การชนต่อ ห้ามขยายอายุคำสั่ง ลบฉาก หรือหยุดคำนวณฟิสิกส์เมื่อขอความช่วยเหลือเพื่อให้คะแนนสูงขึ้น การฝึกนโยบายไม่ทดแทนการแก้ข้อจำกัดระบบรับส่งคำสั่งและการสอบเทียบ

ไม่มีการเปิด test ที่ยังไม่เปิดเพื่อค้นหาสมมติฐาน ชุด validation ที่เคยเปิดและภาพวินิจฉัยที่ใช้แล้วต้องติดป้ายข้อมูลพัฒนา รอบใหม่ต้องแช่แข็งการแบ่งข้อมูลก่อนฝึก และเกณฑ์วิจัยยังแยกจากเกณฑ์พร้อมใช้งาน

ยังไม่แก้ policy บนเว็บ ไม่ต่อ serial/GPIO ไม่ควบคุมมอเตอร์จริง และไม่อ้างผลจำลองเป็นความแม่นยำภาคสนาม
