# ข้อมูลประวัติสำหรับการเรียนรู้และสัญญาข้อมูล Node/Python

ส่วนนี้เป็นฐานซอฟต์แวร์สำหรับงานวิจัยในตัวจำลอง R2 ยังไม่มีโมเดลที่ฝึกใหม่ ไม่มีการวัดความแม่นยำในการขับเรือ และไม่มีการต่อมอเตอร์จริง ผ่านการตรวจเฉพาะส่วนใหม่ 26 รายการตามแผนที่แช่แข็งก่อนทดสอบ หลักฐานอยู่ใน `work/navigation-history-encoder` และ `outputs/Warirak_Navigation_History_Encoder_Audit.json`

## รูปแบบข้อมูล

`navigation_history_encoder.mjs` อ่านเฉพาะ features ที่ observer สรุปและ sidecar-v2 รับไว้แล้ว ไม่อ่านแพ็กเก็ตวินิจฉัยดิบ ข้อมูลหนึ่งเฟรมมี 78 ค่า รวมประวัติสามเฟรมจากเก่าไปใหม่เป็นเวกเตอร์ 234 ค่า มี present flag และเติมศูนย์ด้านหน้าหากประวัติไม่ครบ ลำดับฟิลด์ หน่วย ตัวหาร และประเภทสถานะกำหนดตายตัวใน `navigation-history-layout.json` พร้อม SHA-256

ข้อมูลประกอบด้วยระยะรอบตัวแปดทิศ ข้อมูลเป้าหมาย ความเร็วตามยาว/ตามขวางและอัตราการหมุนที่มาจากหลักฐานการเคลื่อนที่อิสระ อายุข้อมูล สถานะผู้กำกับและ ACK รวมถึงคำขอเดิมของเฟรมก่อนหน้า ค่าศูนย์ที่วัดได้มี known=1 ส่วนข้อมูลขาดหายใช้ค่า 0 และ known=0 จึงแยกกันได้ ค่านอกขอบเขตกลายเป็น unknown แทนการบีบให้ดูเหมือนค่าที่วัดได้ปลายช่วง

ไม่ใส่พิกัดโลก seed ชนิดฉาก เรขาคณิตเป้าหมายจริง reward หรือค่ามอเตอร์ที่แปลงเป็นความเร็วลงในอินพุต ไม่ใส่คำตอบที่เลือกให้เฟรมปัจจุบัน ประวัติคำขอ operator recovery เป็นเพียงข้อมูลย้อนหลังและไม่เพิ่มเป็น action ของ AI

## เวลาและการตัดประวัติ

อายุคำนวณจากเวลาจับข้อมูลเดิม ณ เวลา encode โดยไม่ประทับเวลาจับใหม่ ข้อมูลที่เก่ากว่า 300 มิลลิวินาทีกลายเป็น unknown; เฟรมเก่าทั้งเฟรมเติมศูนย์ ไม่ยกข้อมูล cached ให้เป็นหลักฐานระยะใหม่ ความเร็วที่วัดอิสระยังแสดงการลอยได้ขณะ STOP แม้ระยะเป็น unknown

รับประวัติใน epoch เดียวกันและลำดับเวลา/record ที่เพิ่มเท่านั้น ข้าม epoch หรือมีข้อมูลปัจจุบันขัดแย้งกันจะปฏิเสธ หาก record ไม่ต่อเนื่องหรือห่างกันเกิน 300 มิลลิวินาทีจะตัดประวัติ ก่อนเรียก encoder ผู้เรียกยังต้องใช้ sidecar เพื่อจัดการ manual/disarm/cancel/fault และส่งเฉพาะ decision window ของบริบทปัจจุบัน การตัดสิน authority ไม่ได้ย้ายมาอยู่ใน encoder

## ขอบเขต Node/Python

Node สร้างเวกเตอร์เพียงที่เดียว Python `warirak_ai/navigation_wire.py` ตรวจและอ่านเวกเตอร์เดียวกัน จึงไม่สร้าง encoder สองชุดให้สูตรคลาดกัน ใช้ JSON ที่จำกัดขนาด ตรวจชนิดข้อมูล ค่าจำกัด one-hot และ known flags แล้วเทียบ SHA-256 ของเวกเตอร์แบบ binary64 little-endian รวมถึง hash ของ layout เครื่องมือตรวจ Python ปฏิเสธ JSON ที่คีย์ซ้ำหรือมี NaN/Infinity

คำขอมี session/request ID, epoch, record, เวลาเดิมและ action mask เจ็ดคำขอ เมื่อคำตอบกลับมาต้องตรงกับคำขอเดิมและเลือกเฉพาะ action ที่อนุญาต กำหนดวันหมดอายุแบบ exclusive ที่เวลาภาพเดิม +300 มิลลิวินาที จึงใช้ไม่ได้ ณ ขอบเวลานั้น แม้ encoder ยังแทนอายุ 300 มิลลิวินาทีได้ การรอ inference ไม่ต่ออายุคำขอ การหน่วง 600 มิลลิวินาทีจึงไม่เปลี่ยนเป็นคำตอบสด

`NavigationInferenceClient` เก็บคำขอที่รอได้ครั้งละหนึ่งคำขอ คำขอใหม่แทนคำขอเก่า ยกเลิกและใช้คำตอบซ้ำไม่ได้ เมื่อเวลาถอยหลังจะ latch fault และต้องสร้าง session ใหม่อย่างชัดเจน การ cancel นี้ยกเลิกเฉพาะบริบท inference ไม่ส่ง STOP ไม่สร้างแรงขับ และไม่มี timer ที่ทำงานเอง ตัวกำกับ R2 เดิมยังเป็นผู้อนุญาตการเคลื่อนที่

คำตอบจาก fixture มีชื่อ `warirak.navigation-validation-fixture.v1` และถูกปฏิเสธโดยค่าเริ่มต้น ผู้ทดสอบต้องอนุญาตอย่างชัดเจน Python fixture ใช้ Q-values ที่กำหนดขึ้นเพื่อทดสอบ masked argmax เท่านั้น ไม่ได้โหลดน้ำหนัก โมเดล optimizer หรือระบบฝึก ส่วนนี้ไม่ใช่ authentication สำหรับเครือข่ายหรือ watchdog ของฮาร์ดแวร์

## ผลตรวจและงานถัดไป

ผ่าน targeted tests 26 รายการ: known-zero/unknown, ค่าขาดและ drift, causal history, อายุและลำดับข้อมูล, การตัดประวัติ, การกันข้อมูลวินิจฉัย, การผูกคำตอบกับ mask/deadline/cancel/replay และการส่งค่าทั้ง 234 ค่าพร้อม digest ตรงกันผ่าน Python ใช้บันทึก sidecar เดิมหนึ่งไฟล์เพื่อตรวจรูปแบบโดยไม่เล่นตัวจำลองซ้ำ ไม่ได้เปิด validation/test partition หรือวัดประสิทธิภาพนโยบาย ไม่ได้รันชุดทดสอบทั้งโครงการซ้ำ

ยังไม่มี learned policy, masked Bellman targets, replay buffer, optimizer/checkpoint หรือการต่อ Python inference ระหว่าง rollout การผ่านสัญญาข้อมูลไม่พิสูจน์ความเร็ว Raspberry Pi หรือความพร้อมของเรือจริง งานต่อไปคือออกแบบสถาปัตยกรรมขนาดเล็กและการเรียนรู้ที่ใช้ action mask ทั้งตอนเลือกคำขอและคำนวณเป้าหมาย ทดสอบการบันทึก/กู้คืน RNG, replay, optimizer และนาฬิกา ก่อนแช่แข็ง protocol งบฝึก seed เกณฑ์คัดเลือกจาก validation และขั้นทบทวน test

คงฟิสิกส์และตัวกำกับ R2 รวมกระแสน้ำ ความเฉื่อย ข้อมูลขาด ความหน่วง และการชนหลัง STOP/ขอความช่วยเหลือ เปรียบเทียบกับตัวอ้างอิงที่เข้าถึงข้อมูลเดียวกัน ห้ามเลียนแบบกฎที่ยังชนเป็นคำตอบจริงทุกกรณี รุ่นตรวจจับที่เผยแพร่และนโยบายห้าคำขอบนเว็บไม่เปลี่ยนจากงานส่วนนี้
