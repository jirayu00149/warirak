# แยกการตัดสินใจเดินเรือออกจากคำขอความช่วยเหลือ

การวิเคราะห์หลังรอบR2ใช้ฉากที่เคยอยู่ในชุดฝึก12ฉากต่อบริบท โดยไม่มีการอัปเดตQ ไม่มีvalidation/testใหม่ และไม่สร้างคะแนนประสิทธิภาพชุดใหม่ แผนพร้อมhashถูกบันทึกก่อนเรียกตัววิเคราะห์ใน `work/mission-r2-postmortem/plan.json`

ในบริบทกฎเริ่มต้นพร้อมการสำรวจ0.4 พบคำขอความช่วยเหลือที่เป็นสาเหตุแรกโดยตรงจากตัวเลือกของactor9/12ฉาก อีก3ฉากมาจากตัวกำกับACK ในบริบทนโยบาย6,000ที่ตรึงค่าไว้พร้อมการสำรวจ0.04 พบคำขอโดยตรง8/12ฉาก โดย7ครั้งเกิดขณะสุ่มสำรวจ มี2ฉากจากตัวกำกับACK และ2ฉากไม่มีสถานะขอช่วยก่อนจบ ตัวจำลองยังคำนวณการลอยหลังขอช่วย และคำสั่งแรงขับหลังเข้าสถานะช่วยเป็นศูนย์ครบทุกตัวอย่างที่พบ

สองบริบทนี้ต่างกันทั้งนโยบายและค่าepsilon จึงไม่ใช้ความต่างระหว่างบริบทสรุปผลของepsilonอย่างเดียว และไม่ได้สร้างลำดับQที่เปลี่ยนไประหว่างการฝึกเดิมขึ้นมาใหม่ ตัวอย่างขนาดเล็กนี้ยืนยันกลไกเฉพาะฉากที่ตรวจ ไม่ใช่สัดส่วนสาเหตุของความล้มเหลวทั้ง6,000episodes

## สมมติฐานสำหรับรอบใหม่

ชุดคำสั่งเดิมทำให้การสำรวจเลือก `RECOVERY_REQUEST` และเข้าสถานะรอผู้ดูแลโดยตั้งใจได้ จึงแยกส่วนตัดสินใจเดินเรือให้มีเจ็ดคำสั่ง: STOP, FORWARD, TURN_LEFT, TURN_RIGHT, PIVOT_LEFT, PIVOT_RIGHT และHOLD ส่วนคำขอให้คนประเมินการติดค้างยังมีเส้นทางเรียกโดยoperator และตัวกำกับที่ตรวจACK ความเร็วต่ำ ความก้าวหน้าไม่ชัดเจน manual override และwatchdogยังทำงานตามR2เดิม

ส่วนใหม่นี้เป็นสัญญาข้อมูลในซอฟต์แวร์ `warirak.navigation-only-interface.v1` ยังไม่มีการเชื่อมกับอุปกรณ์หรือระบบยืนยันตัวผู้ใช้ ตำแหน่งการกระทำเดิม0–6คงเดิม ไม่มีการเปลี่ยนแรงขับหรืออายุคำสั่ง400มิลลิวินาที สถานะผู้เรียนมี192,780แบบและตารางQเจ็ดคอลัมน์ ใช้schemaใหม่ `warirak.navigation-only-q-policy.v1` จึงนำตารางแปดคอลัมน์เดิมมาใช้แทนโดยตรงไม่ได้

รอบวิจัยใหม่อยู่ที่ `work/navigation-only-r3-experiment` แผน `navigation-only-r3-experiment-protocol.json` ใช้เส้นทางฝึกหนึ่งครั้งสูงสุด6,000episodes พร้อมผู้สมัคร2,000/6,000 เกณฑ์งานวิจัยและเกณฑ์ความพร้อม **เท่ากับรอบR2** โดยไม่ลดความยากหรือปิดตัวกำกับ ใช้seedฝึกเริ่ม30,000,000 validation32,000,000/32,500,000 และtest34,000,000/34,500,000 ชุดtestของรอบR2ที่28,000,000/28,500,000ยังปิดอยู่

ตัวอ้างอิงและผู้เรียนใช้คำขอเดินเรือเจ็ดแบบและตัวกำกับเดียวกัน ทุกกรณีขอช่วย/ความไม่พร้อมยังอยู่ในตัวหารและยังคำนวณการลอยต่อจนจบepisode แผนและhashต้องถูกตรึงก่อนเริ่มวัดผล เลือกผู้สมัครจากvalidationเท่านั้น หากผ่านจะทบทวนหลักฐานก่อนเปิดtest ไม่เผยแพร่จากการเปลี่ยนชุดคำสั่งเพียงอย่างเดียว

คำสั่งเริ่มหรือresumeหลังตรวจว่าprocessเดิมหยุดแล้ว:

```sh
node ai/train_navigation_only.mjs work/navigation-only-r3-experiment
node ai/train_navigation_only.mjs work/navigation-only-r3-experiment --resume
```

นี่เป็นสมมติฐานที่มีหลักฐานกลไกสนับสนุนและยังต้องวัดผล ไม่อ้างว่าโมเดลฉลาดขึ้นหรือควบคุมเรือจริงได้ก่อนผลประเมิน
