# วารีรักษ์ — Cloudflare รุ่น 1.2.0

เว็บติดตามเรือและพื้นที่ผู้ดูแลระบบของคณะวิศวกรรมศาสตร์ มหาวิทยาลัยทักษิณ รันจากบัญชี Cloudflare ของเจ้าของโครงงานโดยตรง

- Frontend: HTML / CSS / JavaScript เสิร์ฟด้วย Workers Static Assets
- Backend: Cloudflare Worker และฐานข้อมูล Cloudflare D1
- D1 เก็บเรือ ภารกิจ ยอดเก็บขยะ ภาพล่าสุด และทะเบียนการฝึก/รุ่นโมเดล AI อ่านรายละเอียดใน `DATABASE.md` ส่วนผู้ดูแลดูความคืบหน้าการฝึกจากฐานข้อมูลได้ในหน้าฝึก AI
- เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านของเว็บนี้เอง ไม่มีหน้าสมัครบัญชีหรือตั้งรหัสเองสำหรับผู้ใช้ทั่วไป การเปลี่ยนรหัสจำกัดเฉพาะเจ้าของระบบ ไม่มีบริการยืนยันตัวตนภายนอก
- `/` หน้าต้อนรับโครงการ พร้อมปุ่มเข้าดูเรือได้ทันที
- `/monitor` เปิดดูภาพจากเรือและยอดวันนี้ ส่วน `/monitor#reports` ดูรายงานย้อนหลัง 7/30/90 วัน เลือกเรือ ดูรายละเอียดรายวัน แชร์ตัวกรอง และดาวน์โหลด CSV ได้โดยไม่ต้องสมัครสมาชิก ลิงก์เดิม `/#monitor` และ `/#reports` ยังส่งต่อให้ใช้งานได้
- `/demo` ทดลองเดินเรือด้วยนโยบาย Q-learning เทียบกับกฎพื้นฐาน ไม่มีการเขียนยอดจริงหรือสั่งมอเตอร์
- `/updates` รายการปรับปรุงรุ่นเว็บไซต์ และอ่านคู่มือรุ่นนี้ได้ใน `RELEASE_V1_2_GUIDE_TH.md`
- `/login` เข้าสู่ระบบผู้ดูแล และ `/admin#overview` เริ่มจากภาพรวมสถานะจริง ก่อนจัดการอุปกรณ์ ข้อมูลฝึก AI และการจำลอง ไม่มีหน้าจัดการสมาชิกหรือช่องทางสร้างบัญชีบนเว็บ
- ภาพกล้องเป็น JPEG ล่าสุด อัปเดตประมาณทุก 5 วินาที ไม่ใช่วิดีโอสตรีม
- จำนวนเก็บขยะจริงนับเฉพาะเหตุการณ์ยืนยันเก็บ แยกจากข้อมูลจำลอง และนับวันตาม Asia/Bangkok

## พัฒนาและ deploy

### เชื่อม Raspberry Pi 5

หน้า `/admin#system` มีชุดติดตั้งและขั้นตอนรับ Device token สำหรับส่งสถานะ Pi จริง ส่วน `/monitor` แสดงอุณหภูมิ CPU, RAM, พื้นที่ว่าง และเวลาเปิดเครื่อง โดยใช้ `hardware/pi/monitor_agent.py` ซึ่งใช้ Python มาตรฐาน ไม่ต้องติดตั้ง AI ซ้ำ อ่าน [คู่มือเชื่อม Pi](hardware/pi/MONITOR_TH.md) การเชื่อมนี้ไม่สั่งมอเตอร์และไม่เพิ่มยอดเก็บขยะ แบตเตอรี่ที่ยังไม่มีเซนเซอร์แสดงเป็นไม่มีข้อมูล

เมื่อแก้ agent หรือคู่มือ ให้รัน `py -3.13 tools/package_pi_monitor.py` ก่อน build เพื่ออัปเดตชุดดาวน์โหลดสาธารณะที่ไม่มีรหัสอุปกรณ์

สำหรับกล้อง iPhone ชั่วคราว ดู [คู่มือกล้องมือถือ](hardware/pi/IPHONE_CAMERA_TH.md) และ `hardware/pi/phone_camera.py` ใช้สตรีม RTSP/MJPEG จากแอป ใช้ token เดิม มีโหมด check ที่ไม่ส่งภาพ โหมด run ส่งภาพล่าสุด และ --detect ใช้ NCNN จากชุด Pi เดิม แพ็กด้วย `py -3.13 tools/package_phone_camera.py` ไม่เปลี่ยน run_boat หรือเฟิร์มแวร์ ESP เดิม

ใช้ Node.js 22.13 ขึ้นไป และ Python 3.11 ขึ้นไปสำหรับชุดฝึก AI

```sh
npm ci
npm run build
npx wrangler d1 migrations apply DB --local
npm run dev
```

ฐานข้อมูล local แยกจากฐานข้อมูลบน Cloudflare ต้องสร้างผู้ดูแลในฐานข้อมูลที่ต้องการใช้งานตามหัวข้อถัดไป

```sh
npx wrangler login
npm run deploy
```

`wrangler.jsonc` ผูก D1 กับบัญชีเจ้าของโครงงานไว้แล้ว หากนำไปติดตั้งบัญชีใหม่ ให้เปลี่ยน `account_id` สร้าง D1 ด้วย `npx wrangler d1 create warirak-db` แล้วใส่ `database_id` ที่ได้รับก่อน deploy ลิงก์จริงแสดงในผลลัพธ์ Wrangler

## สร้างผู้ดูแลครั้งแรก

```sh
node tools/create-owner.mjs
npx wrangler d1 execute DB --local --file ../work/warirak-cloudflare-owner.sql
```

บนระบบจริงเปลี่ยน `--local` เป็น `--remote` ใช้คำสั่งนี้ครั้งแรกหลังสร้างตารางเท่านั้น เครื่องมือสร้างรหัสผ่านสุ่ม 256 บิต เก็บรหัสไว้ในไฟล์ส่วนตัว `../outputs/Warirak_Cloudflare_Admin_Credentials.json` และสร้าง SQL ซึ่งมีเพียงค่าแฮชใน `../work/warirak-cloudflare-owner.sql` เครื่องมือจะไม่เขียนทับรหัสเดิม

ห้ามเพิ่มไฟล์รหัสผ่านลง Git หรืออัปโหลดใน assets เว็บไม่มีหน้าจัดการสมาชิกหรือ API สร้างบัญชี เซสชันหมดอายุใน 8 ชั่วโมง และใช้คุกกี้ HttpOnly / Secure / SameSite=Strict บน HTTPS

การทดสอบไม่ครอบคลุมการทำงานของเรือจริง Raspberry Pi, กล้อง และ ESP32 ยังต้องเชื่อมต่อและทดสอบหน้างาน นโยบายขับเรือที่แนบมาผ่านการทดสอบในตัวจำลองเท่านั้น

อ่านคู่มือใน `frontend/assets/` และใบอนุญาต `LICENSE` / `THIRD_PARTY_NOTICES.md` ซอร์สที่นำขึ้นเว็บดาวน์โหลดได้จากเมนูคู่มือของผู้ดูแล

## โมเดลตรวจจับและการฝึกขับเรือ

รุ่นตรวจจับปัจจุบันคือ **public-v4-2026-10-28** ใช้ข้อมูลเดิม1,715ภาพ ฝึกเพิ่มจริง27รอบจากสูงสุด45รอบ โดยถ่วงน้ำหนักคลาส เลือกจากvalidation: mAP50–95 รุ่นเดิม38.32% → รุ่นใหม่39.08% ฝาขวดลดเล็กน้อยแต่ยังผ่านเกณฑ์ที่กำหนดไว้ ขนาดภาพ800พิกเซล ผล test เดิมที่เคยเปิดแล้วได้mAP50–95 37.09% และNCNN37.17% ตัวเลขนี้ไม่ใช่ผลชุดอิสระใหม่หรือผลกล้องบนเรือจริง อ่าน `frontend/assets/models/MODEL_CARD_PUBLIC_V4_TH.md` และ `TRAINING_V4_REPORT_TH.md` ข้อมูลและน้ำหนักเดิมยังเก็บไว้สำหรับอ้างอิง

เครื่องมือเตรียมข้อมูลสาธารณะและฝึกอยู่ใน `ai/warirak_ai/public_dataset.py`, `extend_caps.py`, `train_public.py` และ `finetune_public.py` ชุดแรกใช้ TACO กับ SC-FloatWaste 910 ภาพ ชุดปรับละเอียดเพิ่มภาพฝาขวดจาก Reviewed ExtendedTACO เฉพาะ train เป็น 1,325 ภาพ โดยคง validation/test เดิมและกรองภาพที่ทับซ้อน

`ai/evaluation-protocol.json` กำหนดการเลือกโมเดลและความละเอียดจาก validation ก่อนประเมิน test ใช้ `python -m warirak_ai.finalize_detector` เพื่อสร้างรายงานสุดท้ายที่ไม่เลือกจากคะแนน test น้ำหนักจริง รายงาน และชุด NCNN แสดงในหน้าฝึก AI เมื่อมี `frontend/assets/models/release.json` โมเดลไม่ได้ทำงานบน Cloudflare; inference ทำบน Pi/คอมพิวเตอร์ของเรือ

ชุดเผยแพร่ก่อนหน้า public-v2 ฝึกอุ่นเครื่อง 40 รอบและปรับละเอียด 60 รอบ เลือกภาพ 800 × 800 จาก validation ผล test 142 ภาพ: mAP50 42.23%, mAP50–95 29.44% ส่วน NCNN mAP50–95 29.41% ที่วัดบน CPU คอมพิวเตอร์ ดาวน์โหลดชุดโมเดลจาก `frontend/assets/models/release.json` ซึ่งชี้ไปยังน้ำหนัก รายงาน เกณฑ์ความเชื่อมั่น คู่มือ และแหล่งข้อมูล ผลนี้ยังไม่ใช่ผลจากกล้องเรือในบ่อจริง

ซอร์ส ZIP ไม่รวม ZIP โมเดลและ ZIP ข้อมูลภาพ เพื่อลดขนาดไฟล์ หากติดตั้งจากซอร์สที่แตกใหม่ ให้ดาวน์โหลดไฟล์ตามช่อง `ncnn` และ `package` ใน release.json จากเว็บต้นทาง แล้ววางใน `frontend/assets/models/` ตามชื่อเดิมก่อน build/deploy ส่วนชุดข้อมูล YOLO เต็มอยู่ในไฟล์ส่งมอบ `Warirak_YOLO_Public_Dataset.zip` บนเครื่องเจ้าของโครงงาน

นโยบายขับเรือฝึกใหม่ได้ด้วย `node ai/train_navigation.mjs` สคริปต์เลือกนโยบายจาก validation และประเมินสนามทดสอบชุดใหม่ นโยบายที่แนบฝึก 20,000 รอบ ทดสอบ 1,000 สนาม: เก็บสำเร็จ 981 / ชน 14 / หมดเวลา 5 ตัวจำลองและคำสั่งเสนอของ Pi ยังไม่ส่งคำสั่งไปมอเตอร์จริง

รอบปรับปรุง public-v3 เพิ่มข้อมูลเป็น 1,715 ภาพและฝึกจริง 25 รอบก่อน early stopping ผล validation ที่เทียบในรอบเดียวกันได้ mAP50–95 รุ่นเดิม 38.32% และรุ่นทดลอง 37.23% ขวดดีขึ้นแต่ฝาขวดลดลง จึงคง public-v2 ตามเกณฑ์ที่กำหนดก่อนฝึก ดูผลจริงใน `frontend/assets/models/TRAINING_V3_REPORT_TH.md` และ `training-public-v3-report.json` รอบนี้ไม่ประเมิน test เดิมซ้ำและไม่อ้างเป็นผลภาคสนาม

## งานพัฒนา AI ต่อเนื่อง

รอบ public-v4 ผ่านเกณฑ์ validation และการตรวจ NCNN แล้ว จึงเป็นรุ่นเผยแพร่ปัจจุบัน โดยยังใช้ชุดข้อมูล public-v3 เดิม อ่านแผน วิธีใช้ `visual_pilot` และข้อจำกัดใน `ai/CONTINUOUS_DEVELOPMENT_TH.md` การทดลองเดินเรือ stress-v2 ไม่ผ่านเกณฑ์จึงคงนโยบายเดิม มีการแยกเวลาที่อ่านภาพออกจากเวลาประมวลผลเสร็จและทดสอบการหยุดเมื่อข้อมูลไม่พร้อมแล้ว

รอบทดลองเดินเรือ memory-v3 เพิ่มSTOPและประวัติคำสั่ง ฝึก16,000/40,000รอบและผ่านเกณฑ์เปรียบเทียบvalidation แต่ยังไม่แทนนโยบายที่หน้าเว็บใช้ เพราะยังชน27.2%ในสนามยากสังเคราะห์และพบการลอยชนขณะSTOP ดูรายงาน i/NAVIGATION_MEMORY_TH.md หรือเมนูฝึกAIขับเรือบนเว็บ นโยบายนี้ใช้schemaใหม่และไม่ได้ต่อมอเตอร์จริง
