# ผลฝึก YOLO สำหรับกล้องบน Pi — camera-v5

วันที่ 14 พฤศจิกายน 2569 · งานฝึกในเครื่อง RTX 2050 · ไม่ได้ฝึกบน Pi ของผู้ใช้

ฝึก YOLO26n จาก public-v4 จำนวน **6 epochs** ที่ภาพ 640 พิกเซล เพื่อทดลองลดภาระประมวลผลภาพบน Pi เทียบกับรุ่นเดิมที่ภาพ 800 พิกเซล ไม่มีการเปลี่ยนความละเอียดโมเดลที่ใช้งานจริงในรอบนี้

| Validation mAP50–95 | รุ่นเดิม 800 px | รุ่นทดลอง 640 px |
|---|---:|---:|
| ค่าเฉลี่ยสองคลาส | 39.08% | 33.60% |
| ขวดพลาสติก | 39.20% | 32.24% |
| ฝาขวด | 38.96% | 34.97% |

**ผล: ไม่ผ่านเกณฑ์ จึงคง public-v4-2026-10-28 บนเว็บและ Pi** เกณฑ์กำหนดก่อนฝึก: ค่าเฉลี่ยต้องเพิ่มอย่างน้อย 0.003 และแต่ละคลาสลดไม่เกิน 0.02 ไม่ลดเกณฑ์หลังเห็นผล รุ่นทดลองเก็บเป็นหลักฐานวิจัย ไม่ส่งออก NCNN หรือแทนที่โมเดลใช้งาน

## ข้อมูลที่ใช้

ใช้ข้อมูลสาธารณะที่คัดไว้ใน public-v3 รวม 1,715 ภาพ แบ่งฝึก 1,426 / validation 147 / test เดิม 142 ภาพ ไม่ดาวน์โหลดภาพซ้ำหรืออ้างว่าเป็นชุดข้อมูลใหม่ ตรวจไฟล์ SHA-256 ขนาดภาพ ป้ายกำกับ ภาพซ้ำ และกลุ่มถ่ายอีกครั้งก่อนฝึก ผ่าน audit กลุ่มถ่าย 954 กลุ่ม

- [TACO ต้นฉบับ](https://github.com/pedropro/TACO): ขวดพลาสติกและฝาขวด ป้ายกำกับ CC BY 4.0; ภาพตามใบอนุญาตรายภาพ
- [SC-FloatWaste](https://huggingface.co/datasets/OliviaWuYJ/sc-floatwaste): ฉากขยะลอยน้ำ CC BY 4.0 ใช้คลาสขวด ตัดคลาสฝาที่กำกวม ไม่ถือว่าฝาทุกประเภทเป็นฝาขวด
- [ExtendedTACO-reviewed](https://huggingface.co/datasets/roboticslaburjc/ExtendedTACO-reviewed): ภาพฝึกเพิ่มเติมที่ตรวจป้ายกำกับและความซ้ำตาม provenance เดิม

ข้อมูลมีภาพไม่มีเป้าหมาย 234 ภาพ และกรอบเล็กกว่า 8 พิกเซล 49 กรอบ ชุด validation ถูกใช้หลายครั้งแล้ว **คะแนนนี้ไม่ใช่ความแม่นยำภาคสนามหรือชุดอิสระใหม่** test เดิมเคยเปิดผลมาก่อน แต่รอบนี้ไม่ประเมิน test และไม่ใช้เลือกโมเดล ดู revision, hash และข้อจำกัดในรายงาน JSON และ DATA_CREDITS.md

## บนเว็บไซต์

หน้า /monitor แสดงกรอบจาก YOLO ชนิดขยะ จำนวนในภาพ และความมั่นใจสูงสุดของแต่ละชนิด ผลแนบมากับภาพเดียวกัน โดยอัปเดตภาพประมาณทุก 5 วินาที เมื่อไม่มีผล YOLO หรือภาพเก่า ระบบแสดงสถานะตรงตามจริง จำนวนตรวจพบไม่เพิ่มยอดเก็บสำเร็จ

ใช้คำสั่งบน Pi ที่ติดตั้งโมเดล NCNN เดิมแล้ว:

```bash
cd ~/warirak-monitor
curl -fL 'https://warirak-monitor.kungmaxzaa.workers.dev/assets/pi/install_yolo_camera.sh' -o install_yolo_camera.sh
bash install_yolo_camera.sh
~/Warirak_Pi5_Kit/.venv/bin/python phone_camera.py run --detect
```

ยังติดต่อ Pi ของผู้ใช้จากเครื่องพัฒนาไม่ได้ในการทดสอบรอบนี้ จึงต้องให้ผู้ใช้รันตัวอัปเดตบน Pi ก่อน ไม่อ้างว่าติดตั้งบนเครื่องจริงแล้ว ไม่มีคำสั่ง GPIO หรือมอเตอร์จากตัวส่งกล้อง
