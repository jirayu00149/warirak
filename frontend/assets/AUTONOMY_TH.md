# ห้องทดลองการขับเรืออัตโนมัติ

ผู้ดูแลเปิดเมนู “ขับอัตโนมัติ” เพื่อทดลองนโยบาย Q-learning บนสระจำลอง ใช้หมายเลขสนามเดียวกันเพื่อเปรียบเทียบผล ฝึกใหม่จากตารางว่างได้ด้วยจำนวนรอบที่เลือก แล้วดาวน์โหลดนโยบายและรายงานทดสอบไว้ก่อนปิดเบราว์เซอร์

ข้อมูลตำแหน่งขยะจริงไม่ถูกป้อนเป็นคำตอบให้ตัวควบคุม ตัวจำลองสร้างสิ่งที่มองเห็น ระยะสิ่งกีดขวาง และสภาพแวดล้อมให้ตัวควบคุมเลือกคำสั่งซ้าย–ขวา เมื่อขยะเข้าปากสายพานจากด้านหน้าและเรือเคลื่อนเข้าอย่างเหมาะสมจึงถือว่าเก็บสำเร็จ

ชุดทดสอบแยก seed จากชุดฝึก ผลสำเร็จในตัวจำลองไม่ใช่ความแม่นยำของกล้อง และไม่รับรองการขับเรือจริง เครื่องมือบน Pi รองรับการประเมินคำสั่งแบบ shadow โดยไม่ส่งคำสั่งมอเตอร์ ต้องเก็บภาพจริง ฝึกตรวจจับ ทดสอบเซนเซอร์ และปรับการควบคุมในสระก่อนใช้งานกับเรือ

นโยบายรุ่นที่แนบฝึก 20,000 รอบ เลือกจาก validation 1,000 สนามที่แยกจากการฝึก แล้วประเมิน test ใหม่ 1,000 สนาม: เก็บสำเร็จ 981, ชน 14, หมดเวลา 5 สนาม เป้าหมายมีหนึ่งชิ้นต่อสนาม รายงานเปรียบเทียบกับตัวควบคุมแบบกฎและคำสั่งสุ่มอยู่ใน navigation-selection-report.json การฝึกและประเมินเหล่านี้ไม่เพิ่มยอดเก็บขยะจริงใน Dashboard
