# คู่มือผู้ใช้ ผู้ดูแล และกล้องเรือ

## ผู้ใช้ทั่วไป

เปิดหน้าหลักของเว็บ เลือกเรือเพื่อดูภาพล่าสุด สถานะ แบตเตอรี่ และยอดเก็บขยะวันนี้ เลือก “ผลการเก็บขยะ” เพื่อเลือกวันที่และดาวน์โหลด CSV ยอดใช้เวลาไทย และรวมเฉพาะการยืนยันเก็บจากอุปกรณ์จริง ไม่มีข้อมูลจำลองรวมอยู่

ภาพอัปเดตประมาณทุก 5 วินาที หากภาพเก่าหรือการเชื่อมต่อขาด ระบบแสดงคำเตือนพร้อมเวลาที่ได้รับภาพ ไม่มีภาพเมื่อยังไม่ได้เชื่อมเรือ

## ผู้ดูแล

เปิด `/login` ใช้ชื่อผู้ใช้และรหัสผ่านส่วนตัวของเว็บไซต์ เซสชันมีอายุ 8 ชั่วโมง เข้าสู่ `/admin` เพื่อเพิ่มอุปกรณ์ ดูรายงาน และใช้ชุดทดลอง AI เว็บไม่มีหน้าจัดการสมาชิกหรือ API สร้างบัญชี

ผู้ใช้ทั่วไปไม่มีสิทธิ์สมัครบัญชี ตั้งรหัสผ่าน หรือเข้าถึงส่วนผู้ดูแล การเปลี่ยนรหัสผ่านจำกัดไว้เฉพาะเจ้าของระบบ รหัสที่ตั้งใหม่จัดเก็บด้วย PBKDF2-SHA256 พร้อม salt และเพิกถอนเซสชันเก่าทั้งหมด ปุ่ม “ออกจากระบบ” เพิกถอนเซสชันที่กำลังใช้งาน

## ต่อกล้อง Raspberry Pi

1. เข้าสู่หน้าระบบและอุปกรณ์ เพิ่มเรือ แล้วบันทึก Device token ที่แสดงครั้งเดียว
2. ติดตั้งชุด AI ใน Pi และทดสอบกล้องก่อน ใช้ `requirements-capture.txt` หากยังไม่ต้องตรวจจับภาพ
3. ตั้งค่า `WARIRAK_DEVICE_TOKEN` ในเครื่อง Pi และใช้ URL ของเว็บนี้เป็น `--url`

```sh
cd ai
python -m pip install -r requirements-capture.txt
export WARIRAK_DEVICE_TOKEN='ใส่โทเคนอุปกรณ์ของคุณ'
python -m warirak_ai.camera_publish --url https://YOUR-WORKER.workers.dev --source 0 --interval 5
```

ตัวอย่างใช้ shell ของ Raspberry Pi แก้ URL ให้ตรงเว็บจริง ห้ามใช้รหัสผู้ดูแลแทน Device token และห้ามใส่โทเคนใน URL ภาพถูกย่อเป็น 640 × 360 และส่ง JPEG ล่าสุดผ่าน HTTPS ฐานข้อมูลเก็บเพียงภาพล่าสุดของแต่ละอุปกรณ์ ไม่มีระบบเก็บวิดีโอย้อนหลัง
