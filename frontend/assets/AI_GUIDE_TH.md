# เตรียมข้อมูลและฝึก AI ของโครงงาน

โครงการมีโมเดลตั้งต้นที่ปรับฝึกด้วยข้อมูลขยะสาธารณะ ดาวน์โหลดน้ำหนัก NCNN และผลประเมินได้จากการ์ดโมเดลในหน้าฝึก AI ผลเป็นของชุดทดสอบสาธารณะ ไม่ใช่ความแม่นยำในสระของมหาวิทยาลัย ชุดเครื่องมือฝึกและชุดโมเดลเป็นคนละไฟล์ ภาพจริงจากกล้องเรือยังจำเป็นสำหรับการปรับฝึกและทดสอบภาคสนาม

1. เก็บภาพขวด ฝาขวด ฉากไม่มีขยะ แสงสะท้อน และสิ่งรบกวน จากมุมกล้องและความสูงจริงบนเรือ
2. ใน Dataset Studio ตั้งกลุ่มถ่ายภาพตามวันและสถานที่ นำเข้าภาพ ตีกรอบขยะทุกชิ้นที่เห็นชัด และตรวจทานป้ายกำกับทุกภาพ
3. สำรองโครงการเป็น ZIP ภาพกับป้ายกำกับอยู่ในเบราว์เซอร์ ไม่ได้อัปโหลดขึ้นฐานข้อมูลเว็บอัตโนมัติ
4. แบ่ง train / validation / test ตามกลุ่มถ่ายภาพ ห้ามย้ายภาพติดกันจากคลิปเดียวกันไปคนละชุด ประเมินผลแยกขวดกับฝาขวด
5. ส่งออก YOLO แล้วทำตามคำสั่งในเมนู “ฝึก AI” ใช้ชุดทดสอบที่กันไว้หลังเลือกโมเดลแล้วเท่านั้น

โมเดลเริ่มต้นคือ YOLO26n จาก Ultralytics ใช้เพื่อปรับฝึกด้วยข้อมูลของโครงงาน การฝึกบนคอมพิวเตอร์และการดาวน์โหลดน้ำหนักเริ่มต้นต้องมีอินเทอร์เน็ต ส่งออก NCNN เพื่อทดลองบน Pi 4 แล้ววัดอัตราภาพจริงกับขนาดภาพที่ใช้ ฝาขวดเล็กอาจต้องปรับมุมกล้องหรือระยะตรวจจับ

โค้ดและ Ultralytics ใช้ AGPL-3.0 อ่าน LICENSE และ THIRD_PARTY_NOTICES.md ก่อนเผยแพร่ผลงานต่อ

## การฝึกจากข้อมูลสาธารณะที่จัดให้

TACO ใช้ป้ายขวดพลาสติกและฝาขวด ส่วน SC-FloatWaste ใช้เฉพาะขวดพลาสติกและภาพน้ำที่ตรวจแล้วว่าไม่มีป้ายขยะ ภาพที่มีหมวดฝาภาชนะไม่ชัดเจนถูกตัดออก การปรับละเอียดเพิ่มตัวอย่างฝาขวดจาก Reviewed ExtendedTACO เฉพาะ train และกรองความซ้ำกับ validation/test ก่อนฝึก แหล่งภาพบางส่วนไม่มีข้อมูลรอบถ่ายจริง จึงยังรับรองความเป็นอิสระของทุกฉากไม่ได้

เกณฑ์ความเชื่อมั่นของแต่ละคลาสเลือกจาก validation ส่วน test ใช้หลังเลือกน้ำหนักและขนาดภาพแล้ว ค่า mAP ไม่ใช่อัตราเก็บขยะสำเร็จ ดูจำนวนภาพ ข้อจำกัด แหล่งที่มา และค่าแฮชในชุดโมเดลและ model card

ชุด public-v2 ฝึกเสร็จแล้ว: train 1,036 / validation 147 / test 142 ภาพ เลือกขนาดภาพ 800 × 800 จาก validation ผล test ได้ mAP50 42.23% และ mAP50–95 29.44% ส่งออก NCNN และตรวจบน CPU คอมพิวเตอร์ได้ mAP50–95 29.41% ยังไม่ได้วัด FPS บน Pi 4 หรือผลเก็บขยะจริง ดาวน์โหลดจากการ์ด “โมเดลที่ฝึกแล้ว” ในหน้าฝึก AI คู่มือ PI_START_TH.md ในชุดโมเดลมีคำสั่งใช้งานและประเมินซ้ำพร้อมเกณฑ์ความเชื่อมั่นรายคลาส
