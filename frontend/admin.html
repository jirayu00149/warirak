      1. 01

        เก็บภาพและตรวจป้ายกำกับ

        เริ่มตั้งเป้า 1,500–3,000 ภาพจริง หลายวัน หลายมุมและหลายสภาพแสง รวมภาพไม่มีขยะ 20–30% ตัวเลขนี้เป็นแผนเก็บข้อมูล ไม่ใช่เกณฑ์รับรองความแม่นยำ

      2. 02

        แยกกลุ่มและตรวจข้อมูล

        ใช้กลุ่มถ่ายภาพอย่างน้อย 3 กลุ่ม มีทั้งสองคลาสในชุดฝึก ตรวจสอบ และทดสอบ ไม่แยกเฟรมติดกันไปคนละชุด

      3. 03

        ฝึกและเลือกโมเดลจาก validation

        เริ่มจากน้ำหนักตั้งต้นเพื่อลดทรัพยากร หรือเลือกฝึกจากศูนย์ได้ เก็บชุด test ไว้ประเมินหลังเลือกโมเดล

      4. 04

        ทดสอบจริงก่อนนำลงเรือ

        วัด precision, recall, mAP และความหน่วงบน Pi 4 ส่งออก NCNN แล้วประเมินซ้ำ ความแม่นยำและ FPS ยังไม่มีผลวัดในตอนนี้

      Token ใช้ได้เฉพาะรับข้อมูลของอุปกรณ์นั้น เพิกถอนได้ เก็บ token ไว้บนอุปกรณ์เท่านั้น และอ่านวิธีเชื่อมต่อในคู่มือ

      เชื่อม Pi 5 ในครั้งแรก

      ใช้ Python 3 ที่ติดมากับ Raspberry Pi OS ได้เลย ไม่ต้องติดตั้งโมเดลใหม่ คำสั่งด้านล่างให้รันในหน้าต่าง SSH ที่ขึ้น warirak@warirakpi

      1. เพิ่มอุปกรณ์ด้านบนและคัดลอกรหัสเชื่อมต่อ
        รหัสนี้ใช้เฉพาะ Pi เครื่องนี้ แสดงครั้งเดียวและเพิกถอนได้
      2. ดาวน์โหลดโปรแกรมบน Pi
        mkdir -p ~/warirak-monitor && cd ~/warirak-monitor && curl --fail --show-error --location https://warirak-monitor.kungmaxzaa.workers.dev/assets/pi/monitor_agent.py -o monitor_agent.py
      3. ตั้งค่าแล้วทดลองส่งสถานะ
        python3 monitor_agent.py configure

        วางรหัสเชื่อมต่อเมื่อถาม Paste device token ตัวอักษรจะไม่แสดงขณะวาง กด Enter แล้วรัน

        python3 monitor_agent.py run --once

        เมื่อขึ้น Connected เปิดหน้าติดตามเรือ แล้วเริ่มส่งต่อเนื่องด้วย

        python3 monitor_agent.py run

      หากยังไม่มีเซนเซอร์แบต จะแสดงว่าไม่มีข้อมูล และภาพกล้องจะยังว่าง ยอดเก็บจริงเพิ่มเฉพาะเมื่อมีการยืนยันเก็บขยะเท่านั้น

      อุปกรณ์ข้อมูลล่าสุดแบตเตอรี่อุณหภูมิ Piเวลาที่อุปกรณ์รายงานจัดการ
      ยังไม่มีอุปกรณ์ · ยังไม่ได้รับข้อมูลจากเรือจริง

      ขอบเขตการเชื่อมต่อในรุ่นนี้

      backend รับ telemetry และเหตุยืนยันขยะผ่านสายพานได้ แยกจากการตรวจพบของกล้องและข้อมูลจำลอง เว็บไซต์ไม่ส่งคำสั่งควบคุมมอเตอร์ โค้ดส่งข้อมูลจาก Raspberry Pi มีในชุดโปรเจกต์ แต่ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง

      ข้อมูลในเครื่องและเว็บไซต์ที่เผยแพร่ใช้คนละฐานข้อมูล ภาพฝึก AI ยังไม่อัปโหลดขึ้นเซิร์ฟเวอร์
