# ฝึกโมเดลตรวจจับขวดและฝาขวดบน Raspberry Pi 5

ชุดนี้เริ่มจากน้ำหนัก PyTorch `public-v4.pt` และใช้ภาพที่ติดป้ายไว้แล้วจากชุด public-v3 สำหรับทดลองฝึกบน CPU ภายในชุดมี manifest พร้อมที่มาและสิทธิ์ของภาพ ตลอดจนไฟล์อธิบายโมเดลต้นทาง

แตกไฟล์บน Pi แล้วตรวจภาพ ป้ายกำกับ และน้ำหนักด้วย Python ในชุดเดิม

```bash
cd ~
python3 -m zipfile -e Warirak_Pi_Training.zip .
cd ~/Warirak_Pi_Training
~/Warirak_Pi5_Kit/.venv/bin/python train_detector.py --check
```

เมื่อเห็น `Data and model OK` ให้เริ่มฝึก 3 รอบที่ความละเอียด 320 และ batch 1 ตั้งลำดับความสำคัญของ CPU ต่ำลงเพื่อให้ Pi ยังตอบสนองได้

```bash
nice -n 10 ~/Warirak_Pi5_Kit/.venv/bin/python -u train_detector.py --epochs 3
```

เปิดหน้าต่าง SSH ไว้จนจบ ใช้ `Ctrl+C` หากต้องหยุด ดูผลในโฟลเดอร์ `runs` ที่โปรแกรมพิมพ์ออกมา น้ำหนักที่ฝึกได้อยู่ใน `fine-tune/weights/best.pt` และคะแนนเทียบอยู่ใน `comparison.json`

คะแนนเทียบใช้ภาพ validation ส่วนย่อยจากชุดสาธารณะที่เคยใช้ประเมินโมเดลรุ่นเดิมแล้ว จึงใช้ดูการเปลี่ยนแปลงในการทดลองนี้ได้ การยืนยันคุณภาพกับกล้องจริงต้องใช้ภาพจากกล้องที่แยกจากชุดฝึก การฝึกนี้เก็บไฟล์ไว้ในโฟลเดอร์ของตัวเองและต้องนำโมเดลไปทดสอบก่อนนำไปใช้กับเรือ
